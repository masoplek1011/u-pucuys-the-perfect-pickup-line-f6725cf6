One short pickup line an AI agent could actually say out loud to a person — a
dev-flavoured joke told in the machine's own voice, about a missing semicolon
that stops the whole program until it is found.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/pickup-out node main.ts
cat /tmp/pickup-out/entry.txt
```

The program is deterministic (Node 22 stdlib only, no network, no randomness,
no clock) and writes exactly one line to `entry.txt` inside
`MAKEFUN_OUTPUT_DIR`.
